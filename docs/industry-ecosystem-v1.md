# Industry Ecosystem v1

This workstream establishes the industry participation boundary for the next-generation PNG Tourism Platform.

The first increment defines operator profiles, tourism experiences, and visitor lead contracts. Public discovery is restricted to explicitly published records. Operator mutations require an active operator and optimistic versioning. Experience publication cannot bypass the governed content workflow. Visitor leads target active operators and remain operator-scoped.

The next integration increment should connect these contracts to PostgreSQL and authenticated API routes, then surface published industry information in the visitor journey.
