# PNG Visual Design System v1

## Direction

The next-generation platform uses an immersive Papua New Guinea tourism aesthetic rather than a generic white SaaS interface.

### Core palette

- Night: `#071b2a` — primary shell and navigation
- Deep ocean: `#0b2f3f` — layered surfaces
- Ocean: `#0b6477` — primary interactive accent
- Lagoon: `#0f8b8d` — secondary accent
- Leaf: `#18794e` — trusted/positive states
- Sun: `#f4b942` — action/highlight accent
- Sand: `#f4efe4` — warm visitor canvas
- Mist: `#e8f3f1` — soft content background

## Experience principles

1. **Tourism first:** imagery, place, discovery and journey are visually prominent.
2. **Confident contrast:** dark immersive surfaces frame high-value visitor actions.
3. **Shared language:** visitor, industry, content and TPA workspaces use the same primitives.
4. **Trust is visible:** governed sources, publication state and platform health are clear without exposing internal data.
5. **Responsive by default:** desktop, mobile/PWA and kiosk layouts remain usable without a separate design fork.
6. **Progressive disclosure:** operational density belongs in TPA surfaces; visitor surfaces prioritize discovery and action.

## Current implementation

- Premium global shell and navigation
- Immersive visitor hero
- Shared dark/light surface treatment
- Stronger cards, borders, shadows and status states
- AI Concierge presented as a first-class visitor capability
- Responsive navigation and content spacing
- GitLab Pages preview for visual review

The visual system does not change API, RBAC, persistence or AI governance boundaries.
